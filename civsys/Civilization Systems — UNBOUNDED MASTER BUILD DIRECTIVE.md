# CIVILIZATION SYSTEMS
# UNBOUNDED MASTER BUILD DIRECTIVE
## BUILD THE MAXIMUM VERSION OF THE PROJECT

### THIS IS NOT A HACKATHON BUILD ANYMORE.

The hackathon has ended.

The 48-hour constraints are gone.

The objective is no longer:

> “Get Civilization Systems to 90%.”

The objective is:

> **Transform Civilization Systems into the most sophisticated, coherent, explorable, extensible artificial-civilization laboratory this team can realistically build.**

There are **NO OPTIONAL SYSTEMS** in this directive.

There is no:

- optional
- nice-to-have
- maybe later
- if time permits
- where feasible
- future feature
- stretch goal

Any capability described in this document is part of the target product.

The question is no longer:

> “What can we finish before the competition?”

The question is:

> **“What is the most powerful version of Civilization Systems we can engineer?”**

Build toward that.
